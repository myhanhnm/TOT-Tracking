# Agent entry point

Start here: [README.md](./README.md)

This project is a **client-side Workforce Activity Analytics** supervisor dashboard. No auth, no API, single Pages Router page.

**Before coding:** read `BUSINESS-RULES.md` and `ARCHITECTURE.md`.

**Before UI changes:** read `.agents/skills/minimalist-ui/SKILL.md`.

**Current capabilities:** CSV upload, filters, schedule blocks, rankings, charts, 5-segment timelines, utilization metrics.
